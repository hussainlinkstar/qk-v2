# JM WhatsApp Sales Preview

Standalone Next.js preview of the Joseph Mews WhatsApp Sales cockpit (FE mocks only).

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3010

## Vercel

- Root Directory: this folder (`jm-whatsapp-preview`)
- Framework: Next.js
- Build: `npm run build`
- Output: Next default
